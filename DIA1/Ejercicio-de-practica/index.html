Ejercicio práctico de registro y seguimiento de campers.

¿Qué practica este ejercicio?

La práctica usa cuadros de diálogo para registrar campers, notas iniciales, matrículas y evaluaciones. El menú seguirá preguntando hasta que elijas la opción 0 (Salir).

Consejo: ten a mano los datos de prueba. El menú se controla mediante ventanas emergentes del navegador.
